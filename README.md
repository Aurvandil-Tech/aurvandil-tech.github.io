# aurvandil-tech.github.io

The organisation's GitHub Pages root. It exists for one file: `app-ads.txt`,
which Google AdMob fetches from the root of the developer website named in
each app's Play listing. Wix, which hosts www.aurvandil.tech, cannot serve
that file, so the Play listings name https://aurvandil-tech.github.io instead
and this homepage forwards visitors to the real site.

- `app-ads.txt` — the publisher line AdMob gives for account
  pub-1854495445527794. Add a line here for any other ad network an app uses.
- `index.html` — forwards to https://www.aurvandil.tech/.

CraftAlley's policy pages are a separate project site, published from the
Craftalley repository to /Craftalley/.
